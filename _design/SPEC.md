# elisaganea.eu redesign — design spec ("Editorial Mono" structure + "Neon Bloom" accents)

Chosen direction: B (Editorial Mono) with the pink/violet neons of A replacing the green.
Every artboard in this folder must follow this spec exactly so the three pages read as one site.

## 1. Colour tokens — USE THESE LITERAL HEX VALUES, UPPERCASE, NOTHING ELSE
Author every artboard in LIGHT mode with the exact light hexes below. Dark variants are
generated by a script that string-replaces these values, so any other colour will break
the dark mode. Never invent a new colour; never use rgba() except the two glows listed.

| token        | light      | dark (generated) | use |
|--------------|------------|------------------|-----|
| bg           | #F2F0EB    | #141414          | page background (warm paper / charcoal) |
| bg-2         | #EAE7E0    | #1A1A1A          | alternate band (footer, boxed asides) |
| surface      | #FFFFFF    | #1C1C1C          | cards |
| ink          | #121212    | #F2F0EB          | text, strong rules, primary button fill |
| muted        | #5A5A5A    | #9A9A9A          | secondary text |
| rule         | #CFCCC4    | #2E2E2E          | hairlines, borders of secondary controls |
| accent       | #E6297A    | #FF3D8F          | hot pink: labels, underlines, arrows, photo circle |
| accent-2     | #6A5CFF    | #7C6CFF          | violet: the offset ring behind the photo, tiny secondary marks only |
| on-accent    | #FFFEFC    | #141414          | text placed ON a pink fill |
| on-ink       | #F2F0EB    | (=bg)            | text on an ink-filled button — same hex as bg, that is intended |
| glow-pink    | rgba(230,41,122,0.18) | rgba(255,61,143,0.30) | soft radial glow behind the photo circle |
| glow-violet  | rgba(106,92,255,0.14) | rgba(124,108,255,0.22) | secondary glow |
| shadow       | rgba(18,18,18,0.10)   | rgba(0,0,0,0.55)  | card shadow (deck only) |

## 2. Type
- Display: **Anton** (Google Fonts), always UPPERCASE, line-height 0.9, letter-spacing -0.005em.
  Sizes: hero name 176px (desktop) / 92px (mobile); section titles 56px; "LET'S TALK" 140px;
  big numbers (01, 02) 28–64px; CV name 96px.
- Body & UI: **DM Sans** (Google Fonts) weights 400/500/600.
  Body 17px/1.6 (desktop), 15px/1.6 (mobile); leads 19px/1.5; small 13px.
- Labels: DM Sans 11–12px, weight 600, UPPERCASE, letter-spacing 0.18–0.22em.
- Google Fonts link (put inside <helmet>):
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Anton&family=DM+Sans:wght@400;500;600&display=swap">
- Font stacks: font-family: 'Anton', Impact, sans-serif;  font-family: 'DM Sans', 'Helvetica Neue', Arial, sans-serif;

## 3. Components (copy the markup patterns from Main.dc.html)
- **Nav**: left uppercase links (active one has border-bottom 1px ink); centre monogram "E⟋G"
  (Anton 22px, a 1px rotated bar between the letters); right: language switch "EN RO" (active
  = accent colour + border-bottom 1px accent; inactive = muted), theme toggle = 44×44 square
  with 1px rule border and a moon icon (light mode), then "Get in touch ↗" text link.
- **Primary button**: height 48px, padding 0 24px, NO border-radius, background ink, text on-ink,
  DM Sans 13px 600 uppercase 0.12em.
- **Secondary button**: same, transparent with 1px ink border.
- **Text link**: uppercase 12px 600 0.14em + 14px "north-east arrow" icon in accent.
- **Section header**: Anton 28px number ("01") + uppercase label, then a 1px rule; then an
  Anton 56px uppercase title. Sections are separated by 1px rule borders, never boxes.
- **Facts / list rows**: rows separated by 1px rule lines; label uppercase 11px muted on the left,
  value 15px ink on the right.
- **Card (swipe deck)**: surface background, 1px ink border, NO radius, padding 32px,
  pink kicker label, Anton number, title DM Sans 28px 600, body 15px muted, tag chips
  (uppercase 11px, 1px rule border, padding 6px 10px), "Read more ↗" link. Stacked cards
  behind are rotated -4deg / -2deg. Shadow token only on the deck.
- **Link-list row (links page)**: 56px tall, 1px ink border, icon 18px left, label 15px 600
  + optional sub 12px muted, north-east arrow right in accent. Rows stacked with 10px gap.
- **Photo treatment**: the cut-out portrait (blazer.avif) with filter: grayscale(1) contrast(1.08),
  standing on a filled ACCENT circle, with a second circle of the same size drawn only as a 1px
  ACCENT-2 border, offset 24px right and 24px up; behind both a radial glow-pink blob.
- **Icons**: inline SVG only, 24-grid, stroke 1.8, round caps. Never emoji. Paths are in
  src/icons.sh (ico / ico2 helpers) — copy the SVG markup verbatim.
- Hit targets in mockups: never below 44px.

## 4. Layout
- Desktop artboards are 1440px wide with 64px side margins. Mobile is 390px wide with 20px margins.
  The links page is 430px wide (mobile-first; centred on desktop).
- Root element: fixed width, explicit background token, min-height matching the artboard frame
  height in canvas.json (surplus paints bg). Normal document flow; use display:flex / display:grid
  with gap for every sibling group (no margins-between-siblings, no inline whitespace layout).
- Grids: grid-template-columns in the exact shape repeat(N, minmax(0, 1fr)) or explicit px tracks.
- Language switch, theme toggle, and the three nav destinations (Work = "/", CV = "/cv", Links = "/links")
  appear on every page.

## 5. Content — real copy only
All copy comes from `../_data/cv.yml` (home, CV) and `../_data/links.yml` (links page).
Do not invent projects, numbers, clients or testimonials. Projects section: use the three
`highlights.cards` entries as cards 01–03 plus the "Project coming soon" placeholder from
`projects.items` as card 04 (dashed 1px rule border, no link).
Site copy is English (default language). Romanian appears only where the spec asks for a
language-switch demo.

## 6. .dc.html format rules (the canvas format — every rule matters)
- File skeleton, verbatim:
  <!doctype html><html><head><meta charset="utf-8"><script src="./support.js"></script></head>
  <body><x-dc><helmet>…fonts link + <style>…</style>…</helmet> …markup… </x-dc></body></html>
  Keep the `<script src="./support.js">` line exactly; do not add any other <script>.
- Static artboards: NO <script data-dc-script>, no {{ }} handlebars anywhere.
- Canonical HTML: close every element, double-quote every attribute, inline `style="…"` for all
  visual properties (the editor edits inline styles). The <helmet><style> holds only
  body{margin:0;font-family…}, a/a:hover colours, and @keyframes if any.
- Images: `<img src="blazer.avif">` — bare filename, double-quoted; only blazer.avif, shades.avif,
  bus.avif, topdown.avif exist (all transparent cut-outs, ~900px tall).
- No fake browser chrome or fake phone status bars. No lorem ipsum. No emoji.
- Text that must stay on one line: keep it short rather than shrinking type below 11px.
